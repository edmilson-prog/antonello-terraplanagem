# Hazard

The signature motif: a diagonal amber/dark construction-tape stripe. Use it sparingly as a brand emphasis bar — directly under the sidebar wordmark and across the top of the content area.

```jsx
<Hazard />                 {/* 8px — under the brand lockup */}
<Hazard variant="header" /> {/* 6px — top of the main content */}
```

Purely decorative. Don't stack multiple hazard bars in one view — one or two per screen keeps it a signature, not noise.
