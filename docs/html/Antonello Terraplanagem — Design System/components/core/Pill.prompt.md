# Pill

Small monospace count/label bubble. Sits at the right of a card header or after a nav item to show a tally.

```jsx
<Pill>4 vinculadas</Pill>
<Pill>R$ 32.400 em aberto</Pill>
```

Muted mono text, inset background, hairline border, fully rounded. Numbers/values use the mono font by default.
