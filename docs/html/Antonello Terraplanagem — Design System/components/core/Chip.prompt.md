# Chip

Neutral rounded tag with an amber icon. Used for capability/attribute lists such as the equipment an operator is cleared to run.

```jsx
<Chip icon="truck">Escavadeira CAT 320</Chip>
<Chip icon="tractor">Retro JCB 3CX</Chip>
<Chip icon="forklift">Pá XCMG</Chip>
```

Filled inset background, full border, 22px radius. Not a status — use StatusChip/Badge for state.
