# IconButton

Square, icon-only button for toolbars and row actions (theme toggle, overflow menus).

```jsx
<IconButton icon="sun" label="Tema claro" />
<IconButton icon="pencil" label="Editar" size="sm" />
```

- Always pass `label` — it becomes the `aria-label` and `title`.
- 36px default, 30px `sm`. Muted outline → amber on hover.
